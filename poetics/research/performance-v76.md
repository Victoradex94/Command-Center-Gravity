# Poetics performance pass — Version 76

16 October 2026. Source bases: GitHub main `60d0e74d91426b8e23e86e6e0387a3fdd0e6c2c4` (Version 75 source plus setup documentation); Sites source `ea1c7e7790208340fed7d6f7987e9b9e65ecbd8d`, publication 75. No historical data or relationships were added or removed.

## Changes

- Ten immutable data scripts are delivered as one lossless `atlas-input` bundle. Repeated long strings and object field layouts are stored once. The decoder restores the original globals and every field. Readable research/data source files remain unchanged; rebuild with `python scripts/fingerprint-assets.py` (Python standard library only).
- Immutable record, edge, search-text and city indexes replace repeated lookups. Filter count tables are rebuilt once per draw; state map category counts use one pass over eligible records. Alphabetical ordering is reused.
- Font CSS discovery moves from a CSS import to explicit head links and preconnections. The same Afacad/Comfortaa families, weights and swap behavior remain.
- Phone-width baseline QA exposed the exploration actions beyond the horizontal city rail (347px rail / 983px scroll content). A scoped mobile CSS layout gives the actions their own visible rows; desktop remains one horizontal toolbar.
- Fingerprinted delivery files and an additive Version 76 snapshot are generated. Games still load only on the Games route. Detailed state geometry remains lazy and cached.

## Measurements and checks

See `performance-v76-verification.json`, generated by `node test-fast-startup.cjs`.

- Initial local script/style references: 26 → 17 (35% fewer).
- Referenced raw local asset bytes: 845,695 → 630,506 (25.4% smaller).
- Estimated per-file gzip bytes: 186,461 → 180,081 (3.4% smaller). This is a local estimate, not observed wire traffic.
- Nine national/category/year/search/zone/state/city/list/empty-result snapshots match Version 75 after normalizing only the release label.
- Complete composed data is identical: 453 entries / 667 relationships, including uncertainty, evidence, sources and typed edges.
- Local Node/VM redraw medians are recorded in the JSON. These DOM-stub measurements exclude layout/paint/network and are not a browser timing guarantee.
- Navigation, state-layer integration and failed-load fallback, UI controls, top cities, frequency bands, zones/categories, entry presentation, source-clutter checks, Nigeria GIS, Games lazy route, game engine and contribution validation passed.

External font CSS/font files, profile images and on-demand state JSON are outside the initial local-asset byte count. The hosted server controls actual compression and caching. No claim of a Lighthouse score, throttled-network timing, or universal device performance is made.
