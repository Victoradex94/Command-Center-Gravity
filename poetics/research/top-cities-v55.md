# Top cities in these results — Preview 55

Approved rule: up to five known cities ranked by matching Atlas entry associations, descending; alphabetical city name breaks ties. No minimum-entry threshold. Active state/zone, city, year, category, format and search filters apply. Zero-count cities are omitted; a smaller result set may show fewer than five.

Known city names come from the existing city→state mapping. Sourced centre coordinates are not required for a directory shortcut, so Aba and Owerri can appear without inventing geographic points. State names, nationwide/online labels and other non-city location strings are not ranked as cities. All cities remain accessible through the existing dropdown.

All Nigeria and Surprise me are separate actions. The city buttons show current counts. A record associated with more than one city can count once in each associated city; these are directory records, not a count of completed events or residents.

Unfiltered baseline: Lagos64, Ogbomoso25, Aba24, Abuja20, Owerri18. Kaduna's state view has Kaduna4 and Zaria4; Abia demonstrates that a one-entry city is still eligible. No dataset or source changes.

Validation covers the ranking, ties, counts, smaller/empty sets, supported filters, inclusion without coordinate data, city selection and national return. Source/harness checks do not establish actual mobile layout or rendered browser behavior.
